# pokemon-sleep-classifier

Classificador binario (Pokemon de olhos fechados vs. abertos) para mapear
cartas de Pokemon TCG e gerar a lista de compras da colecao.

## Setup
    python -m venv .venv
    .venv\Scripts\activate
    pip install -r requirements.txt

## Ingestao
    python src/00_ingestao_catalogo.py
